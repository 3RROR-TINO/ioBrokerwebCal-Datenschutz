# ioBrokerwebCal-Datenschutz
Diese Anwendung wird ausschließlich privat und persönlich genutzt, um eigene Kalenderdaten in ein privates Automatisierungssystem (ioBroker) einzubinden. Es werden keine Daten an Dritte weitergegeben oder gespeichert außer auf dem eigenen privaten Server des Betreibers.
